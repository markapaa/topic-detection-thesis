# Θεματική Κατηγοριοποίηση Πινάκων με Τοπικά Εκτελούμενα LLMs

Πηγαίος κώδικας της πτυχιακής εργασίας **"Θεματική Κατηγοριοποίηση Πινάκων με Χρήση Τοπικά Εκτελούμενων Μεγάλων Γλωσσικών Μοντέλων"** (Τμήμα Πληροφορικής και Τηλεματικής, Χαροκόπειο Πανεπιστήμιο).

Η εργασία διερευνά κατά πόσο μικρά και μεσαία open-source γλωσσικά μοντέλα (IBM Granite 4.1, Google Gemma 4, Meta Llama 3.2, Mistral Ministral 3), εκτελούμενα αυστηρά τοπικά μέσω του πλαισίου **Ollama**, μπορούν να επιτελέσουν το έργο της Θεματικής Κατηγοριοποίησης (Topic Detection) του διαγωνισμού **SemTab**, σε συνδυασμό με ένα υβριδικό σύστημα αξιολόγησης πέραν της αυστηρής λεξιλογικής ταύτισης.

## Περιεχόμενα Repository

| Αρχείο | Περιγραφή |
|---|---|
| `predict_td.py` | Στάδιο 1 — Παραγωγή προβλέψεων. Διαβάζει τους πίνακες, τους σειριοποιεί σε Markdown, και μέσω few-shot prompting (με ενσωματωμένο μηχανισμό αποχής "I don't know") παράγει την πρόβλεψη κάθε μοντέλου για το θέμα κάθε πίνακα. |
| `predict_ablation.py` | Παραλλαγή του παραπάνω για το πείραμα αφαίρεσης (ablation study): ίδια λογική, χωρίς τον κανόνα αποχής, ώστε να καταγραφεί η συμπεριφορά "αναγκαστικής πρόβλεψης" των μοντέλων. |
| `evaluate_td.py` | Στάδιο 2 — Υβριδική αξιολόγηση. Συγκρίνει τις προβλέψεις με τις ετικέτες αναφοράς (Wikidata), πρώτα μέσω λεξιλογικής ταύτισης (substring matching) και, σε περίπτωση αποτυχίας, μέσω μηχανισμού σημασιολογικής αυτο-κρίσης (self-judging) από το ίδιο μοντέλο. |
| `judge_contribution.py` | **Ανεξάρτητο εργαλείο επαλήθευσης** (όχι μέρος του αρχικού pipeline). Αναπαράγει τη στήλη λεξιλογικής ταύτισης απευθείας από τα αρχεία προβλέψεων και ελέγχει τη μαθηματική συνέπεια των αποτελεσμάτων μεταξύ των Πινάκων 5.2, 5.3 και 5.5 της εργασίας, ως μέσο επιβεβαίωσης της ορθότητας τους. |

Αναλυτική περιγραφή της μεθοδολογίας και της αρχιτεκτονικής του συστήματος διατίθεται στο Κεφάλαιο 4 της πτυχιακής εργασίας. Η μεθοδολογία επαλήθευσης του `judge_contribution.py` περιγράφεται στη Σημείωση Μεθοδολογικής Επαλήθευσης της ενότητας 5.4.

## Απαιτήσεις

- Python 3.10+
- [Ollama](https://ollama.com) εγκατεστημένο τοπικά, με τα εξής μοντέλα:
  - `granite4.1:3b`
  - `gemma4:latest`
  - `llama3.2:latest`
  - `ministral-3:latest`
- Βιβλιοθήκες Python: `pandas`, `requests`

Εγκατάσταση εξαρτήσεων:
```bash
pip install pandas requests
```

## Χρήση

1. Βεβαιωθείτε ότι το Ollama τρέχει τοπικά (`ollama serve`) και έχετε κατεβάσει τα παραπάνω μοντέλα (`ollama pull <όνομα-μοντέλου>`).
2. Προσαρμόστε τις μεταβλητές διαδρομής (`TABLES_DIR`, `TD_FILE`) στην αρχή κάθε script ώστε να δείχνουν στα δικά σας δεδομένα.
3. Εκτελέστε το στάδιο πρόβλεψης:
   ```bash
   python predict_td.py
   ```
4. Εκτελέστε το στάδιο αξιολόγησης:
   ```bash
   python evaluate_td.py
   ```
